# LAPIS — 통합 업무 공간

Claude Office와 라피스(하늘색 업무 공간)를 **하나의 화면**으로 합친 대시보드입니다. 주소는 `http://127.0.0.1:4310`.

기존 프로그램의 소스·데이터·봇 수신자는 바꾸지 않습니다. Office는 실행 중인 `http://127.0.0.1:5000`, 물품 대여는 운영 Worker, Telegram은 기존 수신자가 남긴 기록을 연결합니다.

## 화면 (왼쪽 메뉴)

- **업무** — 오늘, 캘린더(월·주·목록, Google 캘린더 양방향 동기화, .ics 내보내기), 업무 흐름, 자료 모음
- **사무실** — 현황판, 부서 관리, 봇·스킬트리, 스킬 마켓 (Claude Office 기능 전체)
- **라피스** — 라피스 대화(클라우드·Hermes), 라피스 학습(기억 보기·정정·가르치기, 스스로 정리한 교훈, 학습 데이터·모델), 계정·Google(로그인, 드라이브·시트·문서·캘린더·메일·영상 연결)
- **연결** — 저장소(내 PC 맡긴 드라이브 · Google Drive · 라피스 라이브러리), 드라이브(사무실에 맡기기·용량), 텔레그램 수신함, 물품 대여
- **관리** — Claude·텔레그램 연결, 설정, 화면 설정(테마·강조색·밀도·글자 크기·메뉴 구성·시작 화면)

테마는 **화이트·하늘색 / 블랙·그레이 / 시스템 따라가기**. Ctrl+K 로 어디서든 빠르게 이동합니다.

## 라피스 계정과 Google

에디터가 쓰던 라피스 클라우드(Cloudflare Worker)에 이 서버가 대신 접속합니다. 로그인 토큰은 `.runtime/data/vault.bin` 에 Windows DPAPI 로 암호화해 보관하고 화면에는 보내지 않습니다. 서버는 허용 목록 안의 경로만 호출합니다(`src/lapis-cloud.mjs`). 시트·문서 쓰기는 항상 미리보기 → 승인 순서입니다.

## 캘린더와 Google 캘린더

일정은 `.runtime/data/calendar.json` 에 저장됩니다. Google 캘린더 연동은 기본으로 **라피스 계정**을 씁니다. 캘린더 화면 → Google 연동 → 「Google 캘린더 연결」을 누르고 Google 화면에서 허용하면 끝입니다(라피스 클라우드가 서버의 OAuth 앱으로 권한을 받고, 이 서버는 `/integrations/google-calendar/*` 프록시로만 일정을 읽고 씁니다). 기본 캘린더와 Google 화면에서 켜 둔 다른 캘린더(공유·구독 포함)를 가져오고, 읽기 전용 캘린더는 가져오기만 합니다. 새 일정은 기본 캘린더에 올라갑니다. 같은 일정이 양쪽에서 바뀌면 나중에 바뀐 쪽을 따릅니다.

라피스 계정 없이 쓰고 싶으면 같은 화면의 「고급」에서 **내 Google Cloud 프로젝트의 OAuth 클라이언트(데스크톱 앱)** 로 이 PC 에서 직접 연결할 수 있습니다.

## 실행·검증

- 실행: `npm start` 또는 `시작.ps1` / 종료: `종료.ps1` (Node.js 24 이상)
- 검증: `npm test`
- Office 화면 갱신: Office가 새 버전이 되면 `OFFICE_SRC=<Office 폴더> npm run build:office-ui` 로 `web/office.js`·`web/office.css`를 다시 만듭니다(직접 고치지 않습니다).

개인 할 일·자료·메모는 이 브라우저(`lapis.workspace.v1`)에 저장되며 다른 PC로 동기화되지 않습니다. Google 계정의 메일·파일 조회는 연결하지 않았고 바로가기와 링크 보관만 제공합니다.

## 설정 파일

개인 주소와 봇 이름은 `config.local.json`(깃에 올라가지 않음)에 둡니다. `config.example.json` 을 복사해 값을 채우세요: `rentalUrl`(물품 대여 서버), `cloudBase`(라피스 클라우드 API 주소), `botUsernames`. 비어 있으면 해당 연결 기능만 꺼진 것으로 안내합니다.

## 시작하기 · 연결 허브 · 봇 스튜디오 (v0.4)

- **회원제 입구**(`web/gate.js`, v0.5): 처음 열면 로그인·회원가입(이메일/아이디 + 비밀번호, Google) 화면만 보입니다. 초기 설정 마법사는 없고, 가입·로그인 즉시 앱으로 들어갑니다. 로그인하지 않으면 서버가 화면 파일 외의 모든 기능(`/api`·`/office`·`/rental`)을 401 로 막습니다.
- **내 계정 · 프로필**(`web/account.js`): 사진·닉네임·전화번호, 설정 동기화, Google 연결, 로그아웃.
- **계정별 보관**(`src/accounts.mjs`): 할 일·일정·Google 연결 정보는 `<데이터>/accounts/<계정ID>/` 에 계정마다 따로 저장됩니다(이 기능 이전의 자료는 처음 로그인하는 계정이 한 번만 이어받음). 브라우저 저장소 키도 계정별 이름표로 나뉩니다.
- **클라우드 동기화**(`web/sync.js` ↔ 서버 `/dashboard-sync`): 화면 설정·할 일·일정·메모와 AI 연결 여부(로그인 정보 자체는 제외)를 계정에 저장해, 다른 PC 에서 로그인하면 이어집니다. Claude·GPT·Google 로그인과 토큰은 PC 마다 다시 합니다.
- 개발: `npm run dev:lapis -- --fake-lapis-cloud` 로 가짜 서버에서 가입·로그인·프로필·동기화를 끝까지 시험할 수 있습니다.
- **연결 허브**(`web/hub.js`): Claude·ChatGPT(Codex)·API 키·Google·Ollama 모델·Hermes·Cloudflare 토큰.
- **봇 스튜디오**(`web/studio.js`): 봇·역할·텔레그램 방/주제·스킬·시험 대화·웹 배포. 엔진 호출은 `src/office-routes.json` 허용 목록을 거칩니다(엔진에 새 API 를 만들면 여기에도 추가).
- 개발: 저장소 루트에서 `npm run dev:lapis` (임시 데이터, 엔진+화면). `-- --fake-cloudflare` 를 붙이면 가짜 Cloudflare 로 웹 배포 흐름을 끝까지 시험할 수 있습니다.
- 기본 클라우드 주소는 공식 라피스 클라우드이고, `config.local.json` 의 `cloudBase` 로 바꿀 수 있습니다. `rentalUrl` 을 비워 두면 「물품 대여」 메뉴는 숨겨집니다.
