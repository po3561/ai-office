터미널 없이, 버튼만으로 나의 AI 비서 팀 만들기

LAPIS 는 Claude·GPT·로컬 AI·Hermes 를 한 앱에서 연결하고, 봇을 만들어 텔레그램 방과 주제별로 일을 맡기는 프로그램입니다. 이 가이드는 설치부터 첫 대화, 웹 배포까지 순서대로 안내합니다.

한눈에 보기

처음이라면 아래 5단계만 따라 하세요. 약 10분이면 텔레그램에서 내 봇과 대화할 수 있어요.

  1. 설치LAPIS-Setup.exe 를 받아 실행합니다. (Windows 10/11)
  2. 연결 허브에서 AI 연결쓸 AI(Claude, ChatGPT, 로컬 AI 등)를 한 가지만 연결합니다.
  3. 봇 스튜디오에서 봇 만들기「새 봇 만들기」로 이름과 두뇌(AI)를 고릅니다.
  4. 텔레그램 연결BotFather 에서 받은 토큰을 붙여 넣고, 내 계정을 허용합니다.
  5. 대화 시작텔레그램에서 봇에게 말을 겁니다. 필요하면 웹 주소로 배포합니다.

1. 설치와 시작 마법사

설치 파일은 약 1MB 로 가볍습니다. 큰 도구는 필요한 것만 나중에 받습니다.

  1. 설치 파일 받기Releases 에서 LAPIS-Setup.exe 를 내려받아 실행합니다. 관리자 권한은 필요 없습니다.
  2. 「설치」 누르기앱과 휴대용 Node 를 내려받아 %LOCALAPPDATA%\AI-Office 에 설치합니다.
  3. 시작 마법사에서 쓸 것만 체크설치가 끝나면 LAPIS 가 열리고 「시작 마법사」가 이어집니다. 아래 표에서 쓸 도구만 고르세요. 공식 사이트에서 진행률을 보며 받아 설치하고, 중간에 끊겨도 이어받습니다.

봇의 두뇌가 될 AI 와 외부 서비스를 연결하는 곳입니다. 쓸 것 하나만 연결해도 충분해요.

4. 첫 봇 만들기

왼쪽 메뉴 「사무실 → 봇 스튜디오」에서 시작합니다. 1분이면 됩니다.

  1. 「새 봇 만들기」 누르기봇은 하나만 써도, 여러 개를 만들어 업무별로 나눠도 됩니다.
  2. ① 이름봇 이름을 정합니다. (예: 비서, 기획봇)
  3. ② 두뇌(AI) 고르기연결 허브에서 연결한 엔진 중 하나를 고르고 모델을 정합니다.
  4. ③ 역할(선택)추천 역할에서 고르거나 비워 둡니다. 나중에 얼마든지 추가할 수 있어요.
  5. 「시험 대화」 탭에서 확인텔레그램을 붙이기 전에, 앱 안에서 먼저 말을 걸어 설정을 시험해 보세요.

5. 텔레그램 연결

봇 설정의 「텔레그램 · 방과 주제」 탭에서 위에서부터 차례로 진행합니다.

① 봇 토큰 연결

  1. BotFather 열기「텔레그램에서 BotFather 열기」 버튼을 누릅니다.
  2. 봇 만들기/newbot 을 보내고 봇 이름과 @아이디를 정하면 토큰(123456789:AAH… 모양)을 줍니다.
  3. 토큰 붙여넣기앱에 토큰을 붙여 넣고 「연결」을 누르면 @봇아이디 가 표시됩니다.
토큰은 비밀번호예요. 다른 사람에게 보내지 마세요. 토큰은 봇 폴더에만 저장되고 화면·로그에는 나오지 않습니다. 같은 토큰을 두 곳(두 사무실, 다른 프로그램)에서 동시에 쓰면 메시지를 한쪽만 받아 충돌합니다.

② 내 계정 허용 (6자리 코드)

  1. 봇에게 아무 말이나 보내기텔레그램에서 내 봇을 열고 메시지를 보내면 6자리 코드가 옵니다.
  2. 앱에 코드 입력「쓸 수 있는 사람」에서 「코드로 허용」을 누르면 끝. 봇이 “연결됐습니다”라고 알려 줍니다.

허용된 사람만 봇을 쓸 수 있고, 낯선 사람이 말을 걸면 코드만 안내하고 답하지 않습니다. 허용은 앱에서만 바뀌며 텔레그램 메시지로는 바꿀 수 없어요.

③ 그룹방과 주제(토픽)

  • 봇을 그룹방에 초대하고, 허용된 사람이 아무 말이나 하면 앱의 「방과 주제별 설정」에 그 방이 나타납니다.
  • 방마다 응답 방식(멘션하거나 답장할 때만 / 모든 말에 답하기), 방 기본 역할, 방 지침을 정합니다.
  • 주제가 있는 방은 주제마다 다른 역할·지침을 맡길 수 있어요. 해당 주제에서 /whoami 를 보내면 주제 번호를 알려 줍니다.
  • 방 목록은 「방 현황」 메뉴와 텔레그램 /rooms 에서도 볼 수 있어요.

6. 봇 활용 방법

연결이 끝났다면 이제 일을 맡겨 보세요. 아래는 자주 쓰는 방법입니다.

💬 역할로 나누기

글쓰기, 리서치, 검수처럼 역할을 만들고 방·주제마다 기본 역할을 정하면, 같은 봇이 방마다 다른 전문가로 일합니다.

🔐 권한 정하기

기본 권한은 대화만 / 폴더 읽기 / 폴더 읽기·쓰기 중에서 고릅니다. 폴더를 쓰는 건 Claude·GPT(로그인) 엔진뿐이고, 나머지는 대화만 해요. 처음엔 「대화만」으로 시작하세요.

🧩 스킬 붙이기

“보고서는 개조식으로 쓴다”처럼 일하는 방법을 스킬로 적어 두고 역할에 붙입니다. 스킬 마켓에서 다른 사람이 만든 스킬을 받을 수도 있어요.

📅 일정·할 일 자동 정리

텔레그램에 “내일 오후 3시 팀 회의”처럼 보내면 캘린더 일정으로, “금요일까지 제출”처럼 마감이 있으면 할 일로 정리됩니다. 끄고 켤 수 있어요.

🔌 커넥터

Claude 사무실과 Hermes 에 구글 시트·문서·드라이브, LAPIS 일정·할 일, 직접 고른 MCP 서버를 도구로 연결합니다. 파일을 바꾸는 작업은 항상 미리보기 후 승인 순서예요.

🏢 부서 늘리기 (Claude 사무실)

텔레그램에서 “인사팀 추가해줘”처럼 말하면 부서가 늘고, “앞으로 보고서는 개조식으로 써”라고 하면 봇이 스스로 스킬을 만듭니다.

행사 10월 25일 가을 축제 기획안 만들어줘. 예산 500만원
이번 주 회의 일정 정리해서 알려줘

어떤 AI 를 고를까?

  • PC 를 꺼도 돌아가야 하는 일 → API 키 엔진 + 웹 배포

7. 웹 배포 (PC 없이 돌리기)

봇 하나를 내 Cloudflare 계정에 올려 이름.계정이름.workers.dev 주소로 쓰는 기능입니다. 웹 채팅(비밀번호 보호)과 텔레그램이 PC 없이 동작해요.

  1. Cloudflare 토큰 만들기Cloudflare 대시보드 → 프로필 → API 토큰 → 「Workers 편집」 템플릿으로 만듭니다.
  2. 연결 허브에 토큰 붙여넣기「Cloudflare (웹 배포용)」 카드에 넣습니다.
  3. 봇의 「웹 배포」 탭웹 주소 이름과 접속 비밀번호를 정하고, 웹에서 쓸 엔진(GPT·Claude API 키 또는 Cloudflare 무료 AI)을 고릅니다. 처음이면 workers.dev 계정 이름도 한 번 정해요.
  4. 「올리기」잠시 뒤 웹 주소가 열립니다. 비밀번호는 「비밀번호 보기」로 다시 확인할 수 있어요.
웹에서는 PC 의 파일과 Claude·ChatGPT 로그인(구독), 로컬 AI 를 쓸 수 없어요. 해당 엔진을 쓰던 부분은 배포할 때 고른 클라우드 엔진으로 바뀝니다. 텔레그램을 함께 연결해 올리면 PC 쪽 수신은 멈추고 웹이 대신 받습니다.

올라가는 것은 봇 이름·성격·역할·지침·스킬 글과 선택한 API 키(비밀 값으로만), 텔레그램 토큰(연결한 경우)입니다. 언제든 삭제하거나 PC 로 되돌릴 수 있고, 사용량은 Cloudflare 요금제 한도 안에서 쓰길 권장합니다.

8. 문제 해결

텔레그램으로 보냈는데 봇이 읽기만 하고 답이 없어요

봇 토큰 하나는 한 곳에서만 메시지를 받을 수 있어요. 다른 Claude 창이나 다른 프로그램이 수신권을 가져갔을 수 있습니다. 「관리 → Claude · 텔레그램 → 수신 진단」에서 가로채는 프로세스를 정리하고 전역 설정에서 끈 뒤, 메시지를 다시 보내세요.

낯선 6자리 코드가 와요 / 답을 안 해요

허용되지 않은 사람에게는 코드만 안내합니다. 본인이라면 앱의 「쓸 수 있는 사람」에 코드를 입력하세요. 모르는 사람이라면 그대로 두면 됩니다.

그룹방에서 봇이 말을 안 해요

방의 응답 방식이 「멘션하거나 답장할 때만」이면 봇을 멘션하거나 봇 메시지에 답장해야 해요. 앱의 「방과 주제별 설정」에서 「이 방에서 일하기」가 켜져 있는지, 「모든 말에 답하기」로 바꿀지도 확인하세요.

Claude 로그인이 안 돼요

Claude 데스크톱 앱 로그인과 Claude Code 로그인은 별개입니다. 연결 허브의 Claude 카드에서 「로그인」을 눌러 열린 창에서 마친 뒤 「다시 확인」을 누르세요.

출근(Claude 사무실 켜기)을 눌렀는데 아무 일도 없어요

Claude 로그인, 봇 토큰, bun 설치가 모두 준비됐는지 확인하세요. 처음 한 번은 작업 표시줄의 AI-Office · 사무실이름 창에서 폴더 신뢰 질문에 Enter(Yes)를 눌러야 합니다.

웹 배포가 실패해요

Cloudflare 토큰에 「Workers 편집」 권한이 있는지, 웹용 엔진의 API 키가 저장돼 있는지 확인하세요. 주소 이름은 영문 소문자·숫자·하이픈만 쓸 수 있어요.

봇이나 사무실을 지우면 데이터가 사라지나요?

이름을 직접 입력해야 지워지고, 앱이 만든 봇은 폴더를 보관 위치로 옮겨 두어 되살릴 수 있습니다. 불러온 봇은 파일을 그대로 두고 목록에서만 없어져요.

더 자세한 내용은 README 와 텔레그램 연결 메모, 저사양 PC 문제 해결을 보세요.

안전하게 쓰기

  • 대시보드는 이 PC 안에서만 열리고, 변경 요청은 대시보드 화면이 보낸 것만 받습니다.
  • 봇 토큰·API 키는 화면과 로그에 나오지 않고, 봇은 자기 토큰과 허용 목록을 읽거나 고칠 수 없게 막혀 있어요.
  • 파일은 지우지 않고 보관함으로 옮기며, 외부 발송·게시·결제는 사용자의 승인 뒤에만 합니다.
  • 폴더 권한은 필요한 만큼만 켜고, 중요한 자료는 먼저 백업하세요.
